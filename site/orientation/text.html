ME179: Wheeled Mobile Robotics

Programming and testing the XRP

Program robot motion

  1. Robot behavior

    • UCSBXRP: web app for writing robot programs, running virtual or physical XRP robots, observing movement and sensor readings, and improving behavior through experiments
    • Motion, sensing, and decisions combined in Python: driving forward, turning, stopping near an obstacle, following a line, reaching a destination

  1. IDE and Monitor

    • Home: entry to IDE, the workspace for writing and running Python robot programs; Monitor, the workspace for watching the robot and examining measurements
    • Side by side: program alongside robot motion, readings, and plots; direct comparison between programmed behavior and observed response

  1. Virtual and physical XRP

    • Virtual XRP: program driving simulated wheels; encoder readings changing with wheel rotation; range readings changing with nearby obstacles; floor sensors responding to lines
    • Physical XRP: same program driving the robot's motors and reading its sensors
    • Virtual experiments for developing behavior; physical experiments for measuring effects of wheel slip, motor differences, surfaces, and battery condition

  1. Robot programs and projects

    • Project: program and arena for one robot experiment; Working folder: local location for Projects and recorded runs
    • IDE editor: wheel commands, sensor-based decisions, and repeated control adjustments; Project file list for finding assigned code
    • Program output: printed observations, task results, and errors during execution

  1. Compile, Run, Stop, Reset

    • Compile: checking Python files before a robot experiment; reported errors identifying code needing correction
    • Run: executing the program on the selected Virtual XRP or Physical XRP; sensor readings and motion developing during execution
    • Stop: ending the program and stopping robot motion
    • Reset: returning Virtual XRP to its initial position and heading for another trial

Observe and improve motion

  1. Robot and arena

    • Monitor World view: robot moving among lines, obstacles, and destination markers; path showing where the robot has travelled
    • Path compared with intended motion: drift during straight travel, an overshot turn, arrival at a destination, or collision with an obstacle
    • Different project worlds and obstacle arrangements: different conditions for testing the same behavior; zoom and Fit arena for examining robot motion through the arena

  1. Robot measurements

    • Live telemetry: current robot readings while the program runs; wheel speeds alongside visible movement; forward range as the robot approaches an obstacle
    • Encoder readings for wheel rotation; floor reflectance (light/dark readings) for detecting a line; program-reported measurements for examining control decisions

  1. Motion plots

    • Plots: measurements changing over a run; connection between motion commands and robot response
    • Requested and measured wheel speeds together (Show target values): acceleration, speed above the request, unequal wheel response, or repeated speed fluctuations
    • Range alongside motion: obstacle approach, onset of slowing, and stopping
    • Selected portion of a run: closer examination of a turn, stop, or repeated fluctuation

  1. Adjusting robot behavior

    • Live controls: settings exposed by the running program; adjustments while observing robot motion and measurements
    • Direct experiments with control settings: response before and after an adjustment; effects on wheel speed, turning, tracking, or stopping
    • One change at a time, with a stated expected effect; path and plots as evidence of the resulting response

  1. Recording experiments

    • Automatic recording of measurements during each run; saved trials for examining movement and readings after the robot stops
    • Notes: observations attached to moments in the run, such as beginning a turn or reaching an obstacle
    • Open saved run…: earlier trajectory and plots for comparison with another trial
    • Data export for quantitative comparisons; plot images and world animation for presenting observed behavior

Develop robot behaviors

  1. Demonstrations

    • New project…: starting from a demonstration, tutorial, or assigned challenge; separate Project for each experiment
    • Working examples of curved travel and obstacle-triggered turns; program in the editor alongside observed path and sensor readings; changes to example code compared in another run

  1. Challenges

    • Assigned robot tasks: applying sensing, motor control, and navigation in a working solution
    • Success assessed through robot movement and recorded measurements against task requirements; reuse of working code in later tasks

  1. Sensing and control code

    • Measuring and regulating wheel motion: SensorProcessor estimating travel and speed from encoders; WheelSpeedController adjusting motors toward requested speeds
    • Driving and turning: DifferentialDrive coordinating left and right wheels; Odometry estimating movement from wheel travel
    • Reaching destinations: NavigationController steering toward a destination; GridPlanner finding routes around mapped obstacles

  1. Testing robot behavior

    • Test functions: assigned sensing and control calculations checked against known cases; results in Program output
    • Predicted movement before a virtual trial; observed path, sensor readings, and plots afterward
    • One relevant code change followed by another trial; comparison of stopping, wheel-speed stability, or route tracking

  1. Programming help

    • User Guide: explanations of programming and robot experiments
    • UCSBXRP API: Python classes and functions for wheel control, sensing, navigation, and planning

  1. Physical robot preparation

    • Robot Setup for course software installation; Wi-Fi setup for programs and measurements; wheel and motor calibration, stationary sensor checks, and supervised motor checks before floor experiments

Appendix: Physical XRP setup

  1. Working folder

    • Open Robot Setup; choose Open existing Working folder… for current class work, or Set up fresh Working folder for first use

  1. Connect the XRP

    • Keep wheels raised during setup; switch XRP off, connect USB-C data cable, then switch XRP on
    • Choose connected XRP; select intended controller in device picker, possibly listed as Board in FS mode; Connect this XRP for a recognized controller

  1. Prepare the robot and firmware

    • Follow wizard; Install course firmware, if requested: select temporary RP2350 drive's top level, containing INFO_UF2.TXT; wait for copy completion and drive disappearance; Select restarted XRP
    • Continue to Class Wi-Fi and Prepare XRP; keep USB connected and setup page open through completion

  1. Verify wireless operation

    • Battery power on; unplug USB-C; join computer to network named on setup page; allow local-network access if requested
    • Check wireless connection; wait for Robot setup is complete; choose Open IDE

Appendix: Spiral on the XRP

  1. Open the spiral Project

    • Open existing Expanding spiral Project, or New project…, select Expanding spiral, enter name, and Create

  1. Prepare the program

    • Select Physical XRP in Run on; choose Compile; correct reported errors

  1. Prepare a brief floor trial

    • Instructor approval; starting position and heading from Project README.md and world.json; clear floor and room for curved travel
    • Wheels stationary before Run; keep Ignore obstacles at start unchecked; plan a five-second trial with Stop immediately accessible

  1. Run and stop

    • Choose Run; watch physical movement and Monitor wheel speeds; choose Stop after five seconds, or earlier as needed; confirm wheels stopped
    • Wheels continuing after Stop: switch XRP power off
    • Obstacle stopping dependent on a usable ultrasound echo; manual Stop available throughout the trial

  1. Review the trial

    • Inspect wheel-estimated path, wheel-speed plots, and Program output; add Notes for observations; compare with the virtual spiral

Later sessions: XRP power on; computer on class Wi-Fi; same Working folder open; Wi-Fi setup → Test Wi-Fi → Return to IDE before running.
