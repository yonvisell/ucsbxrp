# XRPLib source

This directory contains the unmodified `XRPLib` 2026.07.1 source and its
`phew` dependency from `Open-STEM/XRP_Firmware` commit
`1914fd636d1d06425cdbec88ae4b998844d1501a`. The release identifies the XRPLib
source revision as `55abed4e219e061d32dd190199bc42d9a1b45366`.

The commissioning bundle installs these files with the course runtime so a
factory XRP does not depend on files left by an earlier installation. The
upstream GPL-3.0 license is retained in
`vendor/licenses/Open-STEM-XRP_Firmware-GPL-3.0.txt`.
